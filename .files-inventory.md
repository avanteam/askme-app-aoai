## 🗂️ Structure Helm

### 📦 Chart Principal
```
helm-chart/
├── Chart.yaml                 # Métadonnées chart
├── values.yaml               # Valeurs par défaut
└── templates/                # Templates Kubernetes
    ├── _helpers.tpl          # Fonctions aide
    ├── namespace.yaml        # Namespace par client
    ├── configmap.yaml        # Configuration
    ├── secret.yaml           # Secrets
    ├── deployment.yaml       # Déploiement
    ├── service.yaml          # Service
    └── ingress.yaml          # Ingress + SSL
```

### 👥 Configuration Clients
```
deployments/clients/
├── askme.avanteam-online.com/
│   └── values.yaml           # Config client principal
└── askme-qsaas.avanteam-online.com/
    └── values.yaml           # Config client QSaaS
```
